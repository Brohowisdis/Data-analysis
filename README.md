# Data Analysis & Wrangling Portfolio

Welcome! This repository contains real-world data processing, cleaning, and analysis projects built using Python, Pandas, and Jupyter Notebooks.

## 🛠️ Projects Included:
1. **Twitter Data Wrangling (`deci_project`)**
   * **The Goal:** Cleaned, assessed, and structured a messy archive of tweet data.
   * **Skills Used:** Handling missing JSON data, dropping duplicates, merging `.tsv` and `.csv` files, data type conversion.
2. **Student Performance Analysis**
   * **The Goal:** Exploratory analysis tracking student metrics and success rates.
3. **Coin Flipping Simulation**
   * **The Goal:** Statistical simulation showcasing probability modeling in Python.
